🐍 Snake Game (Python Tkinter)
Welcome to my Snake Game — a classic arcade game where you control a snake to eat food and grow while avoiding collisions with the walls or yourself.

This project is special to me because it’s the very first game I built using Python! 🚀

📸 Game Preview
Choose your difficulty level: Easy, Medium, or Hard

Navigate your snake with the arrow keys

Eat the red food circles to score points

Avoid crashing into the walls or yourself — or it's Game Over!

Option to play again after the game ends

🛠️ Technologies Used
Python 3

Tkinter (for GUI and game window management)

Random module (for food placement)

🎮 How to Play

Use the arrow keys to control the snake:

⬆️ Up Arrow

⬇️ Down Arrow

⬅️ Left Arrow

➡️ Right Arrow

Select a difficulty on the start screen:

🟢 Easy (slow)

🟡 Medium (normal)

🔴 Hard (fast)

Eat the red food to grow your snake and increase your score.

Avoid colliding with the walls or yourself. If you do — it's Game Over.

You can click "Play Again" to restart anytime after losing.

📌 Features
Clean, minimal GUI with Tkinter Canvas

Score tracking and difficulty selection

Keyboard controls for smooth gameplay

Game Over screen with a restart option

Responsive layout and window centering
